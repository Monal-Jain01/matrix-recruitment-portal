📋 STEP-BY-STEP DEPLOYMENT:

1️⃣  PREPARE MONGODB (1 minute)
   → Go to: https://cloud.mongodb.com
   → Network Access → Add IP Address
   → Select "Allow Access from Anywhere" (0.0.0.0/0)
   → Click Confirm

2️⃣  DEPLOY BACKEND (2 minutes)
   → Go to: https://vercel.com/new
   → Sign in with GitHub
   → Import: Monal-Jain01/matrix-recruitment-portal
   → Root Directory: backend
   → Framework: Other
   → Environment Variables:
     MONGODB_URI=mongodb+srv://monaljain1901:monalj@cluster0.t5fifco.mongodb.net/matrx_recruitment_data
     NODE_ENV=production
   → Click Deploy
   → COPY THE URL (you'll need it next!)

3️⃣  DEPLOY FRONTEND (2 minutes)
   → Go to: https://vercel.com/new (again)
   → Import same repository
   → Root Directory: frontend
   → Framework: Create React App
   → Environment Variables:
     REACT_APP_API_URL=<YOUR-BACKEND-URL-FROM-STEP-2>
   → Click Deploy

4️⃣  UPDATE BACKEND CORS (1 minute)
   → Go to your backend project on Vercel
   → Settings → Environment Variables
   → Add:
     FRONTEND_URL=<YOUR-FRONTEND-URL-FROM-STEP-3>
   → Deployments → Redeploy
